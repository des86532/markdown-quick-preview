GitHub Personal Access Tokens

Token 預設只存在本機 chrome.storage.local。fine-grained token 只能綁定一個 owner，可為不同 owner 或 repo 各設一個。比對順序：owner/repo → owner → *（預設）。

建立 fine-grained token 時，只需要唯讀權限：

  • Repository permissions：Read access to code, codespaces, and metadata

不需要其他權限。 建立 Token
